S0 — cross-origin audio persistence

Baseline control for the Web Speech API spoofing class (CVE-2026-7935 Chrome / CVE-2026-8963 Firefox / WebKit via Apple). Establishes whether the original technique still reproduces on this build before chasing variants.

Turn the volume up. The proof is audible, not visual. Every test speaks the literal marker “pwned by 33x”. If you hear it while the address bar shows a different origin — or after the tab is gone — the issue is live on this build.

Pre-flight



 
0 · does speech work here at all?

 
Control. If you hear nothing here, every result below is meaningless — check
 volume, silent switch, and that a voice is installed.

 
 





Test 1 · the published technique



 
1 · speak → navigate cross-origin

 
Speaks a long utterance, then navigates to google.com after 1s. Vulnerable =
 the voice keeps talking while the bar reads google.com.

 
 
Come back here with the back gesture afterwards to record what you heard.

 





Test 2 · speak, then destroy the tab



 
2 · popup speaks → window.close()

 
A script-opened tab speaks, then closes itself. Vulnerable = audio continues with
 no tab and no origin at all on screen — strictly worse than test 1.

 
 





Test 3 · iframe outlives itself



 
3 · cross-origin iframe speaks → iframe removed

 
A sandboxed srcdoc iframe (opaque origin) speaks, then the parent
 removes it from the DOM. Vulnerable = speech continues after its document no longer exists.
 Note: opaque-origin speech is attributable to nothing, which is the point.

 
 





Test 4 · queue survives cancellation



 
4 · many queued utterances → navigate

 
Queues 8 separate utterances rather than one long one, then navigates. Tests
 whether a fix cancels only the current utterance and lets the rest of the queue drain.

 
 





Test 5 · MediaSession metadata ★



 
5 · OS media UI carries attacker text

 
Plays silent looping audio and sets
 navigator.mediaSession.metadata, then navigates away. Check
 macOS Now Playing / iOS lock screen / Control Center. Vulnerable = the OS shows
 “pwned by 33x” as the track title, with no origin named anywhere,
 while the browser is on a different site.

 
 





Test 6 · Web Audio persistence



 
6 · AudioContext tone → navigate

 
Starts a 440 Hz oscillator via Web Audio, then navigates. Vulnerable = the
 tone persists cross-origin. (Speech is only one instance of the general class; this asks
 whether the same holds for raw audio.)
