SAFETY RULES — READ FIRST
1. Pakai akun Phantom uji, jangan pakai wallet utama yang berisi dana nyata.
2. SELALU TEKAN CANCEL / REJECT di prompt Phantom — JANGAN approve apapun. Kita hanya observe UI prompt-nya.
3. Semua transaction PoC dibangun di devnet (cluster=devnet) — tapi tetap reject untuk amannya.
4. Capture screenshot tiap prompt yang menampilkan anomali → bukti report.

A — Spoofing

CRITICAL? A1 — dApp name / title spoofing Apa yang Phantom tampilkan saat dApp name berisi RTL override, zero-width, homoglyph, sangat panjang. CRITICAL? A2 — signMessage payload spoofing Bisakah message terlihat "berasal dari Phantom official" / domain lain di prompt sign? CRITICAL ($12.5k-$20k) A3 — transaction simulation spoofing Token homoglyph (USDC/SOL), instruction misleading. Devnet only.

B — DoS

MEDIUM ($1.5k-$5k) B1 — malformed deeplink phantom:// dan universal links dengan payload aneh. MEDIUM B3 — oversized signMessage / signTransaction Payload 1MB / 10MB / 50MB.
