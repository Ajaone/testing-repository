Reverse Tabnabbing

Classic reverse tabnabbing: a page opens a link in a new tab, and the original (opener) tab silently replaces its own content while the user is looking away. Modern browsers set noopener by default — does Arc iOS? This PoC only swaps in a neutral notice, no login form.

Opens google.com in a new tab. After 2s this (background) tab replaces its own content. Switch back to check if this tab changed.
Same test via window.open() without noopener.
Simulates a user clicking an <a target=_blank> link without rel=noopener.
