iframe + URI Scheme (CVE-2025-14812 variants)

CVE-2025-14812 was fixed in Arc iOS 1.45.2: iframe-triggered URI-scheme navigation caused wrong domain in address bar. These test bypass variants of that fix.

iframe navigates to tel: scheme while parent navigates to Google. Check bar.
iframe triggers sms: scheme, parent writes phishing during app-switch dialog.
Double-nested iframe triggers shortcuts:// while outer iframe has trusted src.
Sandboxed iframe with allow-top-navigation triggers scheme then navigates top.
srcdoc iframe opens popup, triggers scheme, writes to popup during transition.
Rapidly toggle iframe src between trusted URL and about:blank. Check parent bar.
