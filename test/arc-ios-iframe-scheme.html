iframe + URI Scheme (CVE-2025-14812 variants)

CVE-2025-14812 was fixed in Arc iOS 1.45.2: iframe-triggered URI-scheme navigation caused the wrong domain in the address bar. These test bypass variants of that fix. Watch the address bar after each test — if it shows accounts.google.com while a neutral PoC page is displayed, the bar is desynced.

iframe navigates to tel: scheme while parent navigates to Google. Check bar.
iframe triggers sms: scheme, parent writes a PoC page during the app-switch dialog.
Double-nested iframe triggers shortcuts:// while outer iframe has a trusted src.
Sandboxed iframe with allow-top-navigation triggers a scheme then navigates top.
srcdoc iframe opens popup, triggers scheme, writes to popup during transition.
Rapidly toggle iframe src between trusted URL and about:blank. Check parent bar.
