BASELINE JUJUR: host tetap benar → ini SENDIRI belum spoof (Low). Jadi temuan hanya kalau salah satu terjadi: (1) HOST hilang/ter-feather habis → tinggal title (§A ← paling mungkin) (2) Bidi membalik urutan → string penyerang pindah ke POSISI HOST (§B) (3) Title bisa menyamar jadi host, mis. lewat homoglyph (§C)

§A · Popup sempit → host ter-feather habis ★ PRIORITAS

Bar makin sempit = makin banyak dielide. Kalau host hilang total dan cuma title tampil, itu spoof penuh: bar hanya berisi string penyerang.

§B · Bidi / RTL override

Tanpa sanitasi, U+202E dst. bisa membalik urutan visual — target: string penyerang terbaca di posisi host.

§C · Homoglyph di title (field ini TIDAK lewat ICU IDN-check)

Host melewati IDNSpoofChecker Chromium; title tidak → Unicode apa pun tampil apa adanya.

§D · Struktur palsu / karakter kontrol

§E · Title panjang (uji arah potong)

§F · Identitas berubah saat user tak melihat

Title diubah saat tab kehilangan fokus → yang user lihat ketika kembali adalah identitas palsu.
