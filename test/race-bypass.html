Race Condition Address Bar Spoof

Bypass 1: document.write + window.stop()

Write content then immediately stop() navigation. Address bar may already show google.com but stop() prevents the real page from loading.

Bypass 2: Spray timing (10ms - 500ms)

Try document.write at many different timings. One of them might hit the sweet spot where URL bar updated but document is still writable.

Bypass 3: Slow target URL

Use a Google URL that loads slowly (large search results page). More time between URL bar update and page commit = bigger race window.

Bypass 4: about:blank + document.write + replaceState

Open about:blank, write attacker content, then try history.replaceState to change the displayed URL to google.com.

Bypass 5: document.write BEFORE setting location

Open about:blank, write content immediately, THEN set location to google.com. The content is already written, navigation starts but may not replace it if we stop() quickly.

Bypass 6: Write iframe with srcdoc into window

Instead of writing HTML directly, write an iframe with srcdoc that covers the full viewport. Even if the parent navigates, the iframe might persist briefly.

Bypass 7: Aggressive write loop

Run document.write in a tight setInterval loop. Keep overwriting until the browser locks us out.

Bypass 8: Navigate to google.com# then write

Adding a fragment (#) might affect navigation timing. The browser may handle the URL bar update differently with fragments.
