A2b — escalation probe

A2 proved the address bar prints for an about:// document. That alone is a Low. This page asks the only question that changes the severity: does the false host escape the address bar into Arc's other UI? Every surface that repeats it is an independent misrepresentation, and Site Settings (step 6) would be the serious one.

A fake login form is not possible on this origin — about is in WebKit's builtinSchemesWithUniqueOrigins, so the document has an opaque origin and no markup can ever render inside it. Don't try; document the propagation instead.
